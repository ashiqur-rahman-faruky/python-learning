## Your Main Rule For These 30 Days

Every day, write code. Do not only read or watch.

Use this pattern:

| Step | What to do |
|---:|---|
| 1 | Learn the topic for 20-30 minutes. |
| 2 | Type 3 small examples by yourself. |
| 3 | Solve 5 small problems. |
| 4 | Build or improve 1 small project. |
| 5 | Save the file with a clear name like `day10_notes_app.py`. |
| 6 | Review what failed and write 3 notes about what you learned. |
